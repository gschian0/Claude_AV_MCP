# Prompt library

Prompts that worked, kept so they can be re-run and refined. One file per
prompt; note which servers it uses and what the result was.

Example (`drop-build.md`):

> Using ableton, create a MIDI track called "Riser" with a 16-bar clip that
> rises chromatically. Fire it. Using av-conductor, ramp energy from its
> current value to 1.0 over 30 seconds, then recall the "drop" cue.
